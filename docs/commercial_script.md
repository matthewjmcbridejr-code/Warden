## Storyboard & Shot Breakdown

### Shot 1: The Frustration (0:00 - 0:10)
- **Visual**: Screen capture of a standard AI coding assistant halting mid-workflow with a long markdown error message: *"Please set up Supabase OAuth redirect URLs, run `npx vercel build`, and configure your database migration scripts in your local terminal."*
- **Voiceover**: *"Traditional AI coding tools build half a prototype... and then hand you twenty terminal commands to fix broken redirects, missing databases, and failed deployments."*

### Shot 2: Talk to Warden (0:10 - 0:20)
- **Visual**: Smooth cut to **Warden AI Desk 0.6**. Clean, focused "Talk to Warden" conversation surface with zero cluttered dashboards or open terminals.
- **Action**: Operator types into the prompt:  
  `"Finish this client portal and put it online."`
- **Voiceover**: *"With Warden AI Desk 0.6, you talk to your team like a leader, not a debugger."*

### Shot 3: Autonomous Pipeline Execution (0:20 - 0:35)
- **Visual**: Live event sequence renders seamlessly in Warden chat stream:
  - `Understanding project` — **Done**
  - `Fixing authentication & storage` — **Done**
  - `Deploying preview` — **Done**
  - `Testing` — **9/9 checks passed**
- **Overlay Notification**: *"Working — you can close this window at any time."*
- **Voiceover**: *"Warden routes the work, heals environment variables, provisions real backend infrastructure, deploys preview builds, and runs full Playwright browser verifications."*

### Shot 4: Single-Boundary Operator Control (0:35 - 0:45)
- **Visual**: Interactive **Warden Finish & Release** card renders in the conversation stream:
  - **Badge**: `Ready to publish`
  - **Verification Score**: `9/9 Checks Passed`
  - **Buttons**: `[Review Preview]` · `[Publish]`
- **Action**: Operator reviews live preview tab in one click, returns to Talk to Warden, and clicks `[Publish]`.
- **Voiceover**: *"You stay in control. Destructive production deployments wait for your single-click sign-off."*

### Shot 5: Live in Production & Brain Memory (0:45 - 0:55)
- **Visual**: Production promotion completes. Live card renders:
  - **Badge**: `Live & Verified`
  - **URL**: `https://clientportal-production.mariushosting.com` (`Public Live ↗`)
  - **Memory Notification**: `⚡ Production Release Proof recorded to Warden Brain.`
- **Voiceover**: *"Your verified application is live on the internet. Proof packs and architectural decisions are preserved forever in Brain memory."*

### Shot 6: Closing & Call to Action (0:55 - 1:00)
- **Visual**: Warden AI Desk logo, package badges for `.deb` and Linux Desktop, GitHub release link.
- **Voiceover**: *"Warden AI Desk 0.6. The local-first AI workstation for building and shipping real software."*
